# LIGHT_FLY — Backend (REST API)

REST API для сайта аэропорта **LIGHT_FLY**: справочник рейсов и авиакомпаний,
маркет авиабилетов, личный кабинет со скидочной программой, ролевая система и
двухфакторная аутентификация по email.

## Стек

- **Node.js + Express** — HTTP-сервер и маршруты
- **TypeScript** — типизация
- **PostgreSQL** — база данных
- **Drizzle ORM** — схема, миграции, запросы (чистый JS/TS, без бинарных движков)
- **JWT** (`jsonwebtoken`) + **bcryptjs** — аутентификация и хэширование паролей
- **Zod** — валидация входных данных
- **Nodemailer** — отправка кодов 2FA (с fallback в консоль)

## Требования

- Node.js 18+ (проверено на 22)
- PostgreSQL 14+ (локально, в Docker или облаке)

## Быстрый старт

```bash
cd BackEnd

# 1. Установить зависимости
npm install

# 2. Настроить окружение
cp .env.example .env
#   при необходимости отредактируйте DATABASE_URL под свою БД

# 3. Поднять PostgreSQL
#   вариант А — через Docker (нужен установленный Docker):
docker compose up -d
#   вариант Б — использовать уже установленный локальный PostgreSQL,
#   создав базу и пользователя из строки DATABASE_URL

# 4. Создать таблицы и наполнить демо-данными
npm run db:push      # создаёт схему в БД
npm run seed         # заполняет аэропорты, авиакомпании, рейсы, тарифы, демо-пользователей

# 5. Запустить сервер разработки
npm run dev
```

API поднимется на `http://localhost:3000`. Проверка: `GET http://localhost:3000/api/health`.

## Скрипты

| Команда            | Назначение                                            |
| ------------------ | ----------------------------------------------------- |
| `npm run dev`      | запуск в режиме разработки (авто-перезапуск)           |

## Двухфакторная аутентификация (2FA)

Вход и регистрация подтверждаются 6-значным кодом, который отправляется на email.

- Если в `.env` заданы `SMTP_*` — код уходит **реальным письмом**.
- Если SMTP не настроен — код **печатается в консоль сервера**, а в режиме
  `NODE_ENV=development` дополнительно возвращается в ответе API (поле `devCode`),
  чтобы удобно проверять работу без почтового сервера.

## Скидочная программа (лояльность)

Уровень зависит от суммы покупок и даёт скидку на каждый билет:

| Уровень  | Сумма покупок | Скидка |
| -------- | ------------- | ------ |
| Бронза   | от 0 ₽        | 0 %    |
| Серебро  | от 30 000 ₽   | 5 %    |
| Золото   | от 100 000 ₽  | 10 %   |
| Платина  | от 250 000 ₽  | 15 %   |

## Основные эндпоинты

### Аутентификация (`/api/auth`)

| Метод | Путь               | Описание                                        |
| ----- | ------------------ | ----------------------------------------------- |
| POST  | `/register`        | регистрация, отправка кода подтверждения email  |
| POST  | `/login`           | проверка пароля, отправка кода 2FA              |
| POST  | `/verify`          | подтверждение кода → выдача JWT                  |
| POST  | `/resend`          | повторная отправка кода                          |
| GET   | `/me`              | текущий пользователь (требует токен)            |

### Справочники и рейсы

| Метод | Путь                          | Описание                                 |
| ----- | ----------------------------- | ---------------------------------------- |
| GET   | `/api/airports`               | список аэропортов                        |
| GET   | `/api/airlines`               | список авиакомпаний                       |
| GET   | `/api/airlines/:code`         | авиакомпания и её рейсы                   |
| GET   | `/api/flights/board?type=`    | онлайн-табло (`departures`/`arrivals`)   |
| GET   | `/api/flights`                | поиск рейсов (`from,to,date,cabinClass,sort`) |
| GET   | `/api/flights/:id`            | детали рейса с тарифами                   |
| GET   | `/api/info/airport`           | справочная информация об аэропорте       |

### Личный кабинет (требуют токен)

| Метод | Путь                        | Описание                       |
| ----- | --------------------------- | ------------------------------ |
| GET   | `/api/profile`              | профиль + программа лояльности |
| PATCH | `/api/profile`              | обновление профиля             |
| POST  | `/api/bookings`             | покупка билета                  |
| GET   | `/api/bookings`             | мои билеты                       |
| POST  | `/api/bookings/:id/cancel`  | отмена билета                    |

Авторизация — заголовок `Authorization: Bearer <token>`.

# LIGHT_FLY
Это наш проект, который мы создаем в рамках пратических работ пятого семестра, на занятиях по СПО.
## Суть проекта
  - Создать сайт аэропорта, на котором будет основная информация о самом аэропорте, а также отдельный раздел с возможностью покупки билетов, от различных авиакомпаний.

## Технические возможности проекта
  - REST API
  - DB PostgreSQL
  - Большая информационная страница аэропорта
  - Маркет авиабилетов
  - Личный кабинет + скидочная программа
  - Странички авиакомпаний и туроператоров для поиска предложений от конкретного авиаперевозчика
  - Двухфакторная аутентификация через email
  - Ролевая система пользователей

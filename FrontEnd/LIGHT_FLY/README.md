# LIGHT_FLY

Тут будет находиться весь фронтенд и я буду писать различные заметки и тп. Все файлы которые тут есть это лишь шаблон, созданный при установке Vue 3 в Vite.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```

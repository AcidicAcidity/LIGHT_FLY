# LIGHT_FLY — Frontend (Vue)

Веб-интерфейс сайта аэропорта **LIGHT_FLY**: информационная страница аэропорта,
онлайн-табло, маркет авиабилетов с поиском и фильтрами, страницы авиакомпаний,
вход/регистрация с подтверждением по email и личный кабинет со скидочной программой.

## Стек

- **Vue 3** + **TypeScript** (Composition API, `<script setup>`)
- **Vite** — сборка и dev-сервер
- **Vue Router** — маршрутизация (с защитой приватных страниц)
- **Pinia** — управление состоянием (авторизация)
- Собственная дизайн-система на CSS (тема авиации), без внешних UI-зависимостей

## Требования

- Node.js `^22.18.0 || >=24.12.0` (как указано в `package.json`)
- Запущенный бэкенд (см. `../../BackEnd/README.md`)

## Быстрый старт

```bash
cd FrontEnd/LIGHT_FLY

# 1. Установить зависимости
npm install

# 2. Настроить адрес API (по умолчанию http://localhost:3000/api)
cp .env.example .env

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется на `http://localhost:5173`. Убедитесь, что бэкенд запущен
на `http://localhost:3000`.

## Скрипты

| Команда           | Назначение                              |
| ----------------- | --------------------------------------- |
| `npm run dev`     | dev-сервер с горячей перезагрузкой       |

## Структура

```
src/
├── api/            # слой обращения к REST API (client, endpoints, типы)
├── components/     # переиспользуемые компоненты (навбар, карточка рейса, форма поиска…)
├── composables/    # утилиты форматирования (цены, время, статусы)
├── stores/         # Pinia-хранилища (авторизация, шаг подтверждения)
├── router/         # маршруты и защита приватных страниц
├── views/          # страницы (главная, табло, маркет, кабинет, авторизация…)
└── assets/main.css # дизайн-система
```

## Страницы

- `/` — информация об аэропорте, поиск билетов, популярные направления
- `/flights` — онлайн-табло вылетов и прилётов
- `/market` — поиск и покупка авиабилетов
- `/flights/:id` — детали рейса и выбор тарифа
- `/airlines`, `/airlines/:code` — авиакомпании и их предложения
- `/about` — об аэропорте, услуги, FAQ, контакты
- `/login`, `/register`, `/verify` — вход, регистрация, подтверждение по email
- `/account` — личный кабинет: билеты, программа лояльности, профиль

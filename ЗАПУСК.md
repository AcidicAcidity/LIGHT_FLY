# LIGHT_FLY — как запустить проект

Проект состоит из двух частей:

- **`BackEnd/`** — REST API на Node.js + Express + PostgreSQL (Drizzle ORM)
- **`FrontEnd/LIGHT_FLY/`** — веб-интерфейс на Vue 3 + Vite

Подробные инструкции — в README каждой части. Ниже — краткий порядок запуска.

## 1. Бэкенд (сначала)

```bash
cd BackEnd
npm install
cp .env.example .env          # при необходимости поправьте DATABASE_URL

# поднять PostgreSQL (через Docker) — либо используйте свой локальный PostgreSQL
docker compose up -d

npm run db:push               # создать таблицы
npm run seed                  # заполнить демо-данными
npm run dev                   # API на http://localhost:3000
```

## 2. Фронтенд (в отдельном терминале)

```bash
cd FrontEnd/LIGHT_FLY
npm install
cp .env.example .env          # адрес API (по умолчанию http://localhost:3000/api)
npm run dev                   # сайт на http://localhost:5173
```

Откройте **http://localhost:5173**.

## Демо-доступ

| Роль          | Email               | Пароль        |
| ------------- | ------------------- | ------------- |
| Пользователь  | `demo@lightfly.ru`  | `password123` |
| Администратор | `admin@lightfly.ru` | `admin123`    |

При входе на email отправляется 6-значный код (2FA). Если почтовый сервер (SMTP)
не настроен, код печатается в консоль бэкенда и в режиме разработки автоматически
подставляется в форму подтверждения.

## Что реализовано (MVP по ТЗ)

- Информационная страница аэропорта (о нас, терминалы, услуги, FAQ, контакты)
- Онлайн-табло вылетов и прилётов
- Маркет авиабилетов: поиск по направлению/дате/классу, сортировка, тарифы разных авиакомпаний
- Покупка билета, история и отмена в личном кабинете
- Регистрация и вход с подтверждением по email (двухфакторная аутентификация)
- Скидочная программа лояльности (уровни Бронза/Серебро/Золото/Платина)
- Страницы авиакомпаний с их предложениями
- Ролевая система пользователей (USER / MANAGER / ADMIN)
